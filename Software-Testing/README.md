# Software Testing Portfolio – Finance Tracker

## 1. Overview

This directory contains the software testing documentation, test cases, execution results, API testing collections and automation scripts developed for the Finance Tracker application.

The objective of this portfolio is to demonstrate the application of software testing principles and methodologies throughout the Software Testing Life Cycle (STLC).

## 2. Testing Activities

The following testing activities were carried out:

1. Test Planning – Defined the testing scope, objectives, strategy, resources and schedule.
2. Test Case Design – Designed test cases covering the major functional requirements of the application.
3. Test Execution – Executed test cases and documented actual results against expected results.
4. API Testing – Validated backend API endpoints, HTTP methods, responses, status codes and data handling using Postman.
5. Test Automation – Automated selected user interface test scenarios using Selenium WebDriver and JavaScript.
6. Code Quality Analysis – Used SonarCloud to analyse code quality and verify the configured quality gate.

## 3. Folder Structure

| Folder/File | Description |
|---|---|
| `01_Test_Plan/` | Contains the test plan document defining the testing scope, objectives, strategy and approach. |
| `02_Test_Case_Design/` | Contains test case documentation covering different application modules and functionalities. |
| `03_Test_Execution/` | Contains test execution records, actual results and testing outcomes. |
| `04_API_Testing/` | Contains Postman collections and related API testing documentation. |
| `Test_Automation/` | Contains Selenium WebDriver automation scripts and related files. |
| `Conclusion.md` | Summarises the testing activities, outcomes and overall findings. |

## 4. Testing Tools and Technologies

- **Postman:** Used for testing REST APIs and validating responses.
- **Selenium WebDriver:** Used for automating selected user interface test scenarios.
- **JavaScript:** Used to write automation scripts.
- **SonarCloud:** Used for static code analysis and quality gate verification.
- **Git and GitHub:** Used for version control and maintaining the testing portfolio.

## 5. Testing Coverage

The testing activities covered the following application modules:

- Income Management
- Expense Management
- Category Management
- Budget Management
- Budget Calculation and Tracking
- API Endpoints
- User Interface Functionality

## 6. Test Results

The execution results, test outcomes and supporting evidence are documented in the respective folders.

The API testing collection and Selenium automation scripts are maintained separately to support repeatable testing and validation.

## 7. Conclusion

This portfolio demonstrates the application of software testing methodologies through test planning, test case design, manual execution, API validation and UI automation. It provides documented evidence of the testing process followed to assess the functionality and quality of the Finance Tracker application.
